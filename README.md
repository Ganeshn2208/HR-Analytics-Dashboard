# 📊 HR Attrition Analysis (Excel Dashboard)

## 📌 Overview

This project analyzes employee attrition data to identify key factors influencing employee turnover.

---

## 🎯 Objectives

* Understand attrition trends
* Identify high-risk employee segments
* Analyze department-wise attrition
* Support HR decision-making

---

## 📈 Key Insights

* Higher attrition observed in specific departments
* Younger employees show higher turnover rates
* Job satisfaction impacts employee retention

---

## 📊 Dashboard Features

* Attrition by Department
* Attrition by Age Group
* Attrition by Job Role
* Salary vs Attrition
* Gender-wise analysis

---

## 🛠 Tools Used

* Charts & Dashboards
